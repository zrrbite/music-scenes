# Scene Overview: Timeline

| Year | Event |
|------|-------|
| 1981 | Dark Angel forms in Downey, Los Angeles |
| 1983 | [Possessed](bands/possessed.md) forms in the Bay Area. Metallica moves to San Francisco |
| 1984 | Blasphemy forms in Burnaby, near Vancouver |
| 1985 | *Seven Churches* by Possessed, including the song "Death Metal" |
| 1987 | [Autopsy](bands/autopsy.md) forms in Oakland (Chris Reifert, ex-Death) |
| 1989 | Autopsy's *Severed Survival*. Possessed singer Jeff Becerra is left paralyzed after being shot in a robbery |
| 1991 | Autopsy's *Mental Funeral* |
| 1994 | [Strapping Young Lad](bands/strapping-young-lad.md) forms in Vancouver |
| 1997 | Strapping Young Lad's *City* |
| 2001 | [Decrepit Birth](bands/decrepit-birth.md) forms in Santa Cruz |
| 2004 | [The Faceless](bands/the-faceless.md) forms in Encino, Los Angeles |
| 2007 | Strapping Young Lad ends. [Fallujah](bands/fallujah.md) forms |
| 2008 | *Planetary Duality* by The Faceless |
| 2009 | [Archspire](bands/archspire.md) (Vancouver) and [Rings of Saturn](bands/rings-of-saturn.md) (Bay Area) form |
| 2010 | Decrepit Birth's *Polarity* |
| 2011 | [Zenith Passage](bands/zenith-passage.md) forms |
| 2014 | Fallujah's *The Flesh Prevails*. Archspire's *The Lucid Collective* |
| 2016 | Zenith Passage's *Solipsist* |
| 2017 | Archspire's *Relentless Mutation* |
| 2019 | Possessed's comeback album *Revelations of Oblivion* |
| 2021 | Archspire's *Bleed the Future* |
| 2023 | Zenith Passage's *Datalysium* **(verify)** |
