# Scene Overview: Timeline

| Year | Event |
|------|-------|
| 1976 | The Germs form in LA. Black Flag forms (as Panic) in Hermosa Beach |
| 1977 | X forms. [Descendents](bands/descendents.md) form in Manhattan Beach |
| 1978 | Black Flag's *Nervous Breakdown* EP, the first SST release. [Social Distortion](bands/social-distortion.md) forms in Fullerton |
| 1979 | The Germs' *(GI)*. Circle Jerks form |
| 1980 | [Bad Religion](bands/bad-religion.md) forms. Darby Crash dies |
| 1980–81 | Brett Gurewitz starts Epitaph Records |
| 1981 | Black Flag's *Damaged* (with Henry Rollins). *The Decline of Western Civilization* |
| 1982 | *Milo Goes to College*. Bad Religion's *How Could Hell Be Any Worse?* |
| 1983 | [NOFX](bands/nofx.md) forms. Social Distortion's *Mommy's Little Monster* |
| 1984 | Manic Subsidal (later [The Offspring](bands/the-offspring.md)) forms in Orange County |
| 1986 | 924 Gilman Street opens in Berkeley |
| 1987 | Sweet Children (later [Green Day](bands/green-day.md)) form. Operation Ivy forms |
| 1988 | Bad Religion's *Suffer*. [Pennywise](bands/pennywise.md) forms |
| 1989 | Operation Ivy's *Energy*; the band splits |
| 1990 | Fat Mike starts Fat Wreck Chords. Social Distortion's self-titled album |
| 1991 | [Rancid](bands/rancid.md) forms in Berkeley |
| 1992 | [Blink-182](bands/blink-182.md) forms in Poway |
| 1994 | *Dookie*, *Smash*, *Stranger Than Fiction*, *Punk in Drublic* |
| 1995 | Rancid's *...And Out Come the Wolves*. The first Vans Warped Tour |
| 1996 | Pennywise bassist Jason Thirsk dies. Descendents' comeback *Everything Sucks* |
| 1998 | The Offspring's *Americana* |
| 1999 | Blink-182's *Enema of the State*. NOFX's *The Decline* |
| 2004 | Green Day's *American Idiot* |
| 2008 | The Offspring's *Rise and Fall, Rage and Grace* |
| 2024 | NOFX plays its final shows after 40 years **(verify)** |
