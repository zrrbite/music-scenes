# Scene Overview: Timeline

| Year | Event |
|------|-------|
| 1979 | [The Gun Club](bands/the-gun-club.md) forms in Los Angeles |
| 1981 | *Fire of Love* |
| 1980 | The Birthday Party (Nick Cave, formerly The Boys Next Door) moves from Melbourne to London |
| 1983 | [Nick Cave & the Bad Seeds](bands/nick-cave-and-the-bad-seeds.md) forms after The Birthday Party ends |
| late 1980s | [The Denver Gentlemen](bands/the-denver-gentlemen.md) active in Denver, with David Eugene Edwards and Slim Cessna **(verify)** |
| 1992 | [16 Horsepower](bands/16-horsepower.md) and [Slim Cessna's Auto Club](bands/slim-cessnas-auto-club.md) form in Denver |
| 1994 | Nick Cave's *Let Love In*. Johnny Cash's *American Recordings* |
| 1997 | [The Drones](bands/the-drones.md) form in Perth |
| 2000 | Lynched (later [Lankum](bands/lankum.md)) form in Dublin |
| 1996 | 16 Horsepower's *Sackcloth 'n' Ashes* (A&M). Nick Cave's *Murder Ballads*. Gun Club's Jeffrey Lee Pierce dies |
| 1997 | 16 Horsepower's *Low Estate* |
| 2000 | 16 Horsepower's *Secret South* |
| 2001 | Edwards starts [Wovenhand](bands/wovenhand.md) |
| 2002 | 16 Horsepower's *Folklore*. Wovenhand's debut |
| 2002 | The Drones' *Here Come the Lies* |
| 2004 | Wovenhand's *Consider the Birds* |
| 2005 | 16 Horsepower breaks up. The Drones' *Wait Long by the River…* (wins the first Australian Music Prize) |
| 2006 | Wovenhand's *Mosaic*. The Drones' *Gala Mill* |
| 2008 | The Drones' *Havilah* |
| 2013 | The Drones' *I See Seaweed* |
| 2014 | Lynched's *Cold Old Fire* |
| 2014 | Wovenhand's *Refractory Obdurate* (Deathwish) |
| 2016 | Wovenhand's *Star Treatment*. The Drones' *Feelin Kinda Free* |
| 2016 | Lynched rename themselves Lankum |
| 2017 | Liddiard and Kitschin form Tropical Fuck Storm. Lankum's *Between the Earth and Sky* |
| 2019 | Lankum's *The Livelong Day* |
| 2022 | Wovenhand's *Silver Sash* **(verify)** |
| 2023 | Edwards' [solo](bands/david-eugene-edwards.md) album *Hyacinth* (Sargent House); solo touring follows. Lankum's *False Lankum* (Mercury Prize nominee) |
