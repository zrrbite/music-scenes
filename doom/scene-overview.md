# Scene Overview: Timeline

| Year | Event |
|------|-------|
| 1968 | [Black Sabbath](bands/black-sabbath.md) forms in Birmingham |
| 1970 | *Black Sabbath* and *Paranoid* |
| 1971 | *Master of Reality*. [Pentagram](bands/pentagram.md) forms in the DC area |
| 1979 | [Saint Vitus](bands/saint-vitus.md) forms in Los Angeles (first as Tyrant) |
| 1984 | [Candlemass](bands/candlemass.md) forms in Stockholm. Saint Vitus' debut on SST |
| 1985 | Pentagram's first album (later known as *Relentless*) |
| 1986 | *Epicus Doomicus Metallicus* (Candlemass). *Born Too Late* (Saint Vitus, first with Wino) |
| 1988 | Lee Dorrian founds Rise Above Records |
| 1989 | [Cathedral](bands/cathedral.md) forms |
| 1990 | [Sleep](bands/sleep.md) forms in San Jose |
| 1991 | Cathedral's *Forest of Equilibrium* |
| 1992 | Sleep's *Holy Mountain* |
| 1993 | [Electric Wizard](bands/electric-wizard.md) forms in Dorset |
| late 90s | Sleep records the hour-long "Dopesmoker"; the label refuses it and the band splits |
| 1995 | [Norrsken](bands/norrsken.md) forms in Örebro (first as Winterorb) |
| 1999 | Norrsken's 7" "Armageddon" / "Little Lady" |
| 2000 | Electric Wizard's *Dopethrone*. [Witchcraft](bands/witchcraft.md) forms after Norrsken ends |
| 2004 | Witchcraft's debut on Rise Above |
| 2006 | [Graveyard](bands/graveyard.md) forms in Gothenburg |
| 2011 | Graveyard's *Hisingen Blues*. Pentagram documentary *Last Days Here* |
| 2012 | Witchcraft's *Legend* (Nuclear Blast) |
| 2018 | Sleep's comeback *The Sciences*. Graveyard's *Peace* |
