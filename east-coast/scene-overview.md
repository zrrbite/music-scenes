# Scene Overview: Timeline

| Year | Event |
|------|-------|
| 1983 | Chuck Schuldiner's Mantas (later [Death](bands/death.md)) forms in Florida. [Morbid Angel](bands/morbid-angel.md) forms in Tampa |
| 1984 | Xecutioner (later [Obituary](bands/obituary.md)) forms |
| 1986 | [Immolation](bands/immolation.md) forms in Yonkers |
| 1987 | Death's *Scream Bloody Gore* |
| 1988 | [Cannibal Corpse](bands/cannibal-corpse.md) forms in Buffalo. [Suffocation](bands/suffocation.md) forms on Long Island |
| 1989 | Morbid Angel's *Altars of Madness*. Obituary's *Slowly We Rot* |
| 1990 | Obituary's *Cause of Death*. Cannibal Corpse's *Eaten Back to Life* |
| 1991 | Death's *Human*. *Effigy of the Forgotten*. Immolation's *Dawn of Possession*. [Dying Fetus](bands/dying-fetus.md) forms |
| 1992 | Cannibal Corpse's *Tomb of the Mutilated* |
| 1993 | Morbid Angel's *Covenant* (major label). Cynic's *Focus* |
| 1995 | Death's *Symbolic*. Suffocation's *Pierced from Within*. Corpsegrinder replaces Chris Barnes in Cannibal Corpse |
| 2000 | Dying Fetus' *Destroy the Opposition*. Immolation's *Close to a World Below* |
| 2001 | Chuck Schuldiner dies |
| 2006 | [Revocation](bands/revocation.md) forms in Boston (from Cryptic Warning) |
| 2009 | Revocation's *Existence Is Futile* |
| 2014 | Revocation's *Deathless* |
| 2018 | Revocation's *The Outer Ones* |
| 2022 | Revocation's *Netherheaven*. Immolation's *Acts of God* |
