# Quebec Death Metal

Notes on the death metal scene of Quebec, Canada: the 90s pioneers, the technical and brutal
wave, and the modern progressive / tech-death bands coming out of Montreal and elsewhere in the province.

## About these notes

The first draft came from a conversation with Gemini, then got checked against what is
generally known about these bands. Gemini got a few things wrong (see [sources.md](sources.md)).
Anything marked **(verify)** hasn't been confirmed yet. Check it before treating it as fact.
